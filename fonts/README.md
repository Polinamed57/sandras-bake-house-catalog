# Fonts

The flavour names and headings use **Footlight MT Light** (Monotype), the font the client picked for her brand. It is a commercial font, so the file is not included in this repository.

To build the PDF with the original font, put `FootlightMTLight.ttf` in this folder. It ships with Microsoft Office.

Without it, the catalog falls back to Cormorant Garamond from Google Fonts.
